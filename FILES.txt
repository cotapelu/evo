  └── history.json       - Evolution history with diffs


QUICK START
===========
1. npm install
2. npm run build
3. export ANTHROPIC_API_KEY=sk-ant-...
4. npm start
5. In TUI: /evolution-start, /spawn-agent coder "..."

See QUICKSTART.md for detailed guide.
