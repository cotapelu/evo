## 📦 Components to Build

### 1. TLS/HTTPS Module
- Generate self-signed certs if none provided
- Support Let's Encrypt automation
- HTTP → HTTPS redirect
- WSS (WebSocket Secure)

**Config:**
```yaml
tls:
  enable: true
  certPath: /certs/tls.crt
  keyPath: /certs/tls.key
  auto: false  # auto-generate if missing
```

### 2. JWT Authentication
- Issue tokens on `/auth/login` (if user/password configured)
- Validate on protected endpoints
- Role-based: admin, operator, read-only
- Token refresh

**Headers:**
```
Authorization: Bearer <token>
```

**Roles:**
- `admin` - full access
- `operator` - can spawn children, view metrics
- `read-only` - only metrics/health

### 3. Leader Election (Basic Raft)
- Election based on agent ID & level
- Leader handles cluster-wide decisions
- Failover election on leader loss
- Replicated log for consistency

**API:**
```
GET /cluster/leader
POST /cluster/election  (force new election)
```

### 4. Config Hot-Reload (v1.2-alpha)
- Watches .env file for changes
- Reloads config without restart
- Persists to memory & database
- Notifies plugins

**Supported:**
- logLevel
- apiRateLimit
- resourceLimits
- maxChildren (soft limit)
- security settings

### 5. Children Metrics Aggregation (v1.1-beta)
- Pull metrics from children periodically
- Aggregate totals across cluster
- Store in database
- Expose via `/metrics?aggregated=true`

**Metrics:**
- Total memory across all agents
- Average level
- Health status of cluster
- Number of active children

### 6. Distributed Lock (v1.1-alpha)
- File-based lock for critical sections
- TTL support
- Auto-renewal
- FIFO queue

**API:**
```javascript
await agent.lock.acquire('resource-id', ttl);
// Do critical work
await agent.lock.release();
```

### 7. Rolling Restart Coordinator
- Staggered child restarts
- Maintain quorum during updates
- Zero-downtime deployment
- Rollback on failure

## 🔧 Migration from v1.1

### Easy Upgrade
```bash
# Pull latest
git checkout v1.2
npm install

# Generate TLS certs (optional)
openssl req -x509 -newkey rsa:4096 -keyout key.pem -out cert.pem -days 365 -nodes

# Start with new config
AGENT_ENABLE_TLS=true AGENT_TLS_CERT_PATH=./cert.pem AGENT_TLS_KEY_PATH=./key.pem npm start
```

### Breaking Changes
- HTTP port 3456 redirects to HTTPS if TLS enabled
- All HTTP endpoints require auth (configurable)
- WebSocket uses WSS when TLS enabled
